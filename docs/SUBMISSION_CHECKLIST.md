# Final Submission Checklist

**Deadline:** Before December 5, 2026.

The assignment notes request a project folder, Java folder, multiple files compressed into a ZIP, screenshots of test cases in one PDF or in the ZIP folder, and step-by-step screenshots in logical order with instructions.

## Project and code
- [ ] Final project folder is organized.
- [ ] Java source folder is included.
- [ ] All required Java source files are included.
- [ ] Program compiles successfully on the intended environment.
- [ ] Program runs and completes its expected flow.
- [ ] Input/output, data types, loops, selection statements, and arrays are all present.
- [ ] No known logical or technical errors remain.
- [ ] Final code has been reviewed for readability and organization.

## Evidence and instructions
- [ ] Test cases have been executed.
- [ ] Test-case screenshots are genuine and readable.
- [ ] Test screenshots are combined into one PDF, or included in the ZIP folder.
- [ ] Step-by-step screenshots are arranged in logical order.
- [ ] Instructions explain how to open and use the program.
- [ ] Screenshots match the final submitted version.

## Team
- [ ] Every member has contributed.
- [ ] Contributions are recorded accurately.
- [ ] All members have reviewed the final version.
- [ ] The team is prepared to explain the program.

## Packaging
- [ ] All required files are inside the project folder.
- [ ] Multiple files/folders are compressed into the required ZIP.
- [ ] ZIP filename is clear, for example `Team8_FinalProject.zip`.
- [ ] ZIP opens successfully after compression.
- [ ] No required source files or evidence are missing.
- [ ] A backup copy of the final ZIP is retained by the group.

## Final verification
- [ ] Extract the ZIP to a separate location and verify its contents.
- [ ] Open the extracted project and run it again.
- [ ] Confirm the screenshots and PDF are present and readable.
- [ ] Submit before the deadline.

**Important:** The assignment notes that grades cannot be given when logical or technical errors are present. Prioritize a complete, working, tested submission over adding last-minute features.
